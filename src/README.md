## Instrukcje uruchomienia:

- Stwórz wirtualne środowisko języka python
- Pobierz zależności (`pip install -r requirements.txt`)
- Zainstaluj zależność do biblioteki **datasets** (`pip install datasets`)

- Pobierz dane (`python data/download.py`)

- Uruchom program (`python3 src/solution_155898_156021_155934.py`)
